# data/ — 고객사 제공 샘플 데이터 (가상)

한빛산업 구매팀이 "최근 50건, 자주 거래하는 협력사 위주, 기본 양식 PDF"로 전달한 견적서 샘플.
실제로는 `generator/generate.mjs`가 시드 고정 난수로 생성한 가상 데이터다.

```
data/
├── samples/         # 견적서 PDF 50건 (Q001.pdf ~ Q050.pdf)
├── ground-truth/    # 건별 정답 JSON (평가셋). 실무에서는 "ERP에 입력된 값"에 해당
├── manifest.json    # 건별 요약 (협력사, 양식 스타일, 통화, 품목 수)
└── generator/       # 생성기 + 중간 HTML
```

## 데이터 특성 (고객 인터뷰 내용을 반영)

- 협력사 18곳, 거래가 잦은 곳일수록 많이 등장 (상위 5곳이 절반 이상)
- 양식 5종: ERP 출력형(erp), 엑셀형(excel), 공문형(word), 간이형(simple), 수입업체 영문혼용형(import)
- USD 견적 5건 (부가세 별도, 환율 기재 여부 섞임)
- 유효기간: 날짜형과 "견적일로부터 N일" 상대 표현 혼재
- 날짜 표기 4종 혼재 (2026-09-30 / 2026.09.30 / 2026년 9월 30일 / 2026/09/30)
- 사업자번호, 견적번호, 연락처(전화/이메일)가 일부 건에서 누락
- 같은 부품의 규격 표기가 협력사마다 다름 (6205ZZ vs 6205-2Z)
- 스캔본은 없음 (고객이 물었으나 FDE가 요청하지 않음)

## 재생성

```bash
node data/generator/generate.mjs   # macOS Chrome 필요
```
